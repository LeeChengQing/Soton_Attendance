# Soton Auto-Check V1.0.0 Release

**Updated: 6 October 2026**

## Changes in this update

- Added **Timetable group** to Student profile: Do not filter, Group 1, Group 2, and Group 3. Import filters only Lab sessions clearly marked as belonging to a different group; lectures, tutorials, and sessions with an unknown group stay for review.
- The extension's **Get license key** link opens the website with **Mobile notifications · Semester** preselected.
- Direct visits to the website still default to **Complete experience bundle**; the Mobile notifications selection is scoped to the extension link.
- Activation and recovery now accept the supported legacy, China semester, website standard, and international license key formats. Inputs are normalized consistently before local storage, device registration, and backend hashing, while preserving case-sensitive international prefixes and standard website separators.
- Recovery key inputs support the complete key length and prevent browser auto-capitalization from changing case-sensitive formats.
- Safer form submissions: required answers and dates are checked before clicking Submit. Only explicit success text counts as success. Ambiguous submissions remain pending confirmation locally and are never retried automatically; the cloud event uses the existing `unknown` status for compatibility.
- Improved timetable grid recognition, group extraction, question matching, and automatic form binding.
- Retained optional-date support, Auto-Scan & Save All, and automatic QR/link binding.

## Installation

Download **Soton-Auto-Check-v1.0.0-latest-Windows-macOS.zip**, extract it, and use **Load unpacked** at `chrome://extensions` with Developer mode enabled. To update an existing installation, replace the files in its current extension directory and reload the extension to retain local settings.

**SHA-256:** Published in the GitHub release description and the `.sha256` sidecar.

The existing `v1.0.0` tag is retained; this package update does not move the tag.
