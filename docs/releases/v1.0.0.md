# Soton Auto-Check v1.0.0

首个包含手机提醒付费授权流程的正式发行版。Chrome 扩展内部更新版本为 2.4.0。

## 本版内容

- 支持首学期套餐和手机提醒续期密钥。
- 密钥一次兑换并绑定一台设备；服务端保存密钥哈希，不保存可再次兑换的明文密钥。
- 到期、无授权或无效授权时，服务器不再向该设备发送 ntfy 手机提醒；本机自动打卡继续工作。
- 现有设备需要立即兑换有效密钥，才能继续收到手机提醒。
- 安装包适用于 Windows 和 macOS 的 Chrome 浏览器。

## 管理员上线事项

- 在 368FK 创建首学期套餐与手机提醒续期商品，并将购买按钮配置为各自的商品详情页。
- 使用密钥生成脚本生成库存；在 Supabase 导入哈希 CSV，在 368FK 上架对应的一次性明文密钥。明文库存不要提交到 GitHub。
- 本发行包不包含激活密钥库存，也不包含任何 Supabase 服务端密钥。
