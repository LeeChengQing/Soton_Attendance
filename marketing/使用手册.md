# Attendance 自动打卡｜使用手册

适用版本：**v1.0.0**　｜　适用系统：**Windows、macOS**　｜　浏览器：**Google Chrome 120 或更新版本**

本手册面向收到 ZIP 安装包的学生。**无需运行 `npm install`，也无需安装 Node.js。**

## 1. 安装扩展

1. 保存 `Soton-Auto-Check-v1.0.0-Windows-macOS.zip`。
2. Windows：右键 ZIP，选择“全部解压缩”。macOS：在 Finder 中双击 ZIP 解压。把解压后的文件夹放在固定位置，不要在安装后移动或删除。
3. 在 Chrome 地址栏输入 `chrome://extensions`，打开右上角“开发者模式”。
4. 点击“加载已解压的扩展程序”（Load unpacked），选择解压后**直接包含 `manifest.json`** 的文件夹。Chrome 不能在这一步直接选择 ZIP 文件。
5. 点击工具栏中的 Attendance 图标，进入设置页。若看不到图标，打开扩展程序拼图菜单并固定它。
6. 使用同一个 Chrome 用户登录学校 Microsoft 账号，并允许 Chrome 发送系统通知。

**升级旧版：**先在 `chrome://extensions` 停用旧扩展，避免两个版本同时运行。若用新文件覆盖原来的同一路径，再点击旧扩展卡片的“重新加载”，一般可保留该扩展在当前 Chrome 用户中的资料。若把新版作为另一个文件夹重新“加载已解压的扩展程序”，Chrome 可能将其视为另一个扩展，资料不会自动复制；请重新配置并检查任务。

## 2. 填写学生资料（第 1 区）

输入学号、姓名，选择 Local Student 或 International Student，点击“保存资料”。请与学校表单要求保持一致。学生资料保存在当前 Chrome 用户中。

## 3. 导入并核对课表（第 2 区）

1. 点击“选择课表文件”，上传 PDF、JPG/JPEG 或 PNG。扩展在本机识别课程名称、星期、开始和结束时间。
2. 按星期检查每节课。点开课程卡片，可以修改课程名、星期、时间及停课例外日期。
3. 如果课表同时列出 Group 1、Group 2，请删除不属于自己的组别。识别错误或遗漏时，点击“手动添加课程”。
4. 先完成第 3 区的表单绑定，再点击“一键创建每周自动打卡”。创建后的任务会显示在第 4 区。

任务按星期持续重复，没有自动学期结束日期。课程结束、放假或不再需要时，请删除任务或设置停课例外。

## 4. 绑定二维码或表单链接（第 3 区）

1. 在课程代码卡片中上传二维码图片，或粘贴 Microsoft Forms 填写链接。
2. 点击“打开并核对表单”。如学校要求登录，先在打开的页面完成登录。
3. 检查表单标题、每道题及其资料映射。学号题选“学号”，姓名题选“姓名”，日期题选“当日日期”，Module Delivery 题选“按课程名称自动选”，学生身份题按需要选 Local / International。
4. 勾选“我已核对”，再点击“保存表单绑定”。

同一课程代码只需绑定一次。例如 `COMP1311-LEC`、`COMP1311-TUT` 和 `COMP1311-LAB` 可共用 `COMP1311` 的链接；扩展仍会按具体课程选 Lecture、Tutorial 或 Laboratory/Lab。若表单没有对应课型选项，绑定或执行会停止，请先核对表单。

### 仅填写测试

对于共用链接的课程，先在“仅填写测试的课程课型”中**明确选择**要测试的 `LEC`、`TUT` 或 `LAB`，再点击“测试所选课型 · 不提交”。打开的页面会填写答案，但不会点击提交。请亲自检查学号、姓名、日期、课型和学生身份。通过提示会显示测试的具体课程及 Module Delivery；如果之后改动了答案，通过提示会撤销。

建议每种课型至少测试一次，尤其是 Tutorial 和 Lab。

## 5. 创建与管理每周任务（第 4 区）

完成第 1 至第 3 区后，回到第 2 区点击“一键创建每周自动打卡”。扩展会检查资料、课程时间及表单绑定，然后建立每周任务。重复导入相同课程不会重复创建；同一天的不同上课时段分别保留。

第 4 区可逐条“删除”任务，也可点击“清空本区”删除全部任务。电脑必须保持运行且 Chrome 开启；扩展无法唤醒休眠设备。错过课程结束前 5 分钟的打卡时间时不会自动补交，请按学校要求手动处理。

## 6. 查看通知与记录（第 5 区）

扩展只在 Microsoft Forms 明确返回成功反馈后显示“打卡成功”。失败、结果不明和错过时间会分别记录或通知；“结果不明”不会自动重试，以免重复提交。遇到异常时请打开原表单核对，并按学校要求处理。

## 7. 开通手机提醒

保存学生资料后，设置页会显示专属 ntfy 主题。在手机安装 ntfy 并订阅该主题，之后需完成授权才能收到提醒。

1. 新用户购买“首学期套餐”（¥12）；已开通过的用户购买“手机提醒续期”（¥5/学期）。购买后按商品说明取得自动发货密钥。
2. 在设置页“手机提醒订阅”中输入密钥，点击“激活手机提醒”。每把密钥只能激活一台设备；换设备后需要为新设备单独兑换。
3. 查看授权状态和截止日期。续期密钥按批次对应的学期截止日生效；如果当前授权已覆盖同一学期，再兑换该学期密钥不会额外延长时间。

ntfy 订阅地址本身不代表已获授权。未激活、授权过期或失效时，云端不会发送手机提醒，但本机自动打卡仍可继续运行。v1.0.0 上线后，已有设备也需立即兑换有效密钥，才能继续收到手机提醒。截止日按马来西亚时间当天结束计算。

## 8. “清空本区”分别会删除什么？

| 区域 | 清空内容 | 保留内容 |
| --- | --- | --- |
| 第 2 区 | 当前待核对的课表预览 | 已创建任务、表单绑定、学生资料、打卡记录 |
| 第 3 区 | 保存的课程二维码链接及表单题目映射 | 已创建任务、学生资料、打卡记录 |
| 第 4 区 | 全部已创建的每周任务 | 学生资料、表单绑定、打卡记录 |

清空前会出现确认提示。**清空第 3 区后，现有任务在重新绑定表单前无法自动提交。**

## 常见问题

**Chrome 选择文件夹时看不到 ZIP？** 先解压 ZIP，再选择包含 `manifest.json` 的文件夹。

**上传 PDF 或图片后没有识别出课程？** 尝试更清晰的文件；检查预览并手动添加遗漏课程。扫描课表、模糊图片和复杂排版可能需要人工修正。

**Tutorial 被选成 Lecture？** 在“仅填写测试”前确认选的是 `-TUT`，并检查测试页的 Module Delivery。测试提示应显示 `Tutorial`。也请在 `chrome://extensions` 停用旧版本，避免混用。

**日期不对或不能提交？** 检查电脑的日期、时间和时区。扩展会核对任务日期、马来西亚当天日期及电脑本地日期，并再次检查表单中的实际日期；不一致时停止。

**没有出现成功通知？** 打开第 5 区查看状态，检查 Chrome 通知权限、学校账号登录状态和表单页面。只有表单明确反馈成功才会发出成功通知。

**换电脑或换 Chrome 用户后资料还在吗？** 不会自动同步。资料保存在原 Chrome 用户本机，需要在新环境重新配置。

## 使用边界

本扩展目前是 Chrome 扩展，不是手机 App。它只处理受支持的 Microsoft Forms 页面和题型；表单题目改变、验证码、额外验证或学校登录过期时会停止或提示处理。是否允许使用自动填写工具，请以学校课程规定为准；请仅为自己的实际到课记录使用。
