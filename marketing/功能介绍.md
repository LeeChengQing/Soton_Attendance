# Attendance 自动打卡｜功能介绍

**课表上传一次，按课程结束前 5 分钟自动尝试完成 Microsoft Forms 打卡。**

如果每节课都要反复扫描同一个二维码、填写学号和姓名，Attendance 可以把这些重复步骤整理成每周任务。学生在自己的 Chrome 中完成一次配置，之后由扩展在课程结束前 5 分钟运行，并根据表单返回的结果通知。

## 主要功能

1. **导入课表**：支持 PDF、JPG/JPEG、PNG。扩展在本机识别课程、星期和时间；导入后可逐节检查与修改，也能手动添加课程。
2. **二维码变成课程表单**：上传课程二维码图片或粘贴 Microsoft Forms 链接，核对表单标题与题目后保存。同一课程代码的 Lecture、Tutorial、Lab 可以共用一个表单链接。
3. **按课型填写**：根据课程名称中的 `LEC`、`TUT`、`LAB` 选择对应的 Module Delivery；学号、姓名、学生身份及当日日期按已确认的映射填写。
4. **每周自动任务**：核对课表和表单后，一键创建每周任务。同一天的不同课程分别记录；可设置停课例外日期。
5. **结果通知与记录**：仅在表单明确显示提交成功后提示“打卡成功”。失败、错过时间或结果不明会显示对应状态；结果不明不会自动重试。
6. **本机处理与保存**：课表在本机识别；课程绑定、学生资料和任务保存在学生自己的 Chrome 中，不需要另设云端账号。

## 适用设备

- Windows 和 macOS 使用同一个 Chrome 扩展安装包。
- 接收安装包的用户无需运行 `npm install`，也无需安装 Node.js。
- 目前支持 `forms.office.com` 与 `forms.cloud.microsoft` 的填写表单。

## 使用前须知

自动任务需要电脑保持运行、Chrome 开启，并在同一个 Chrome 用户中保持学校账号登录。电脑休眠、Chrome 关闭、表单变化或登录过期时，任务可能无法完成；扩展会记录并提示人工处理。课程结束后请删除对应的每周任务。请遵守学校的出勤要求，仅在实际到课且允许使用自动填写工具的情况下使用。

**获取方式：**联系卖家获取 Windows/macOS 共用安装包与配置说明。详细步骤见《Attendance 自动打卡｜使用手册》。
